## Premise

Grill My Mind is a skill for Codex, Claude Code, and GitHub Copilot. It opens a localhost mind map where I can describe an idea, answer questions, and choose which suggested branches agents explore. Maps should save readable structured knowledge in the repo and resume across sessions. Use the existing agent, keep context focused, and reach an MVP quickly so we can learn from trying it.

## Findings

A living map for thinking with an agent. Questions sharpen the idea; you choose which research directions become active.

The first trial is ready to explore. The map and question panel save your work locally, and the command bridge lets the agent you are already using pick up a selected branch.

## What we have agreed

- Codex, Claude Code, and GitHub Copilot are the intended environments. This first live trial uses Codex; the other environments still need hands-on checks.
- Suggested branches wait for your activation. Completing research does not automatically accept its conclusion.
- Saved JSON owns the map; readable Markdown lets other agents understand it without the original chat.
- The initial agent mode is intentionally simple and replaceable. Context growth is something to measure in real use.

## What to try

Choose a direction on the map, inspect its details, and activate it when you want to investigate. You can also add a direction of your own. Reopening the workspace preserves the same questions, answers, and suggestions.

The initial context packet for this real exploration was 1,922 characters. That measures map input only, not the agent's total conversation or actual billed tokens.
