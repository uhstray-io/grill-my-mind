# Saved UI prototypes

These are self-contained design snapshots. Open either HTML file directly in a browser; no server, installation, account, or model is required. All research is simulated. Changes remain in memory and reset on reload.

- [Constellation / version 1](01-constellation.html): the chosen direction. Light/dark modes, draggable connected nodes, pan/zoom, questions, and simulated findings. Reset layout restores positions; Reset preview starts the simulation over.
- [Original card-based map](02-original-map.html): retained for comparison. Select cards, drag their headers, explore a branch, answer a sample question, and add directions.

## Decision — 2026-09-23

The user selected Constellation/version 1 for the next working prototype. Research paths/version 2 is rejected as the direction forward. This is a current product decision, not a permanent commitment: the constellation may be enhanced or replaced after real use. The original card map remains a reference, not a competing selected direction.

Keep these snapshots unchanged when enhancing the live application.
```sh
node scripts/verify-prototypes.mjs
```

- Inline JavaScript compiles successfully.
- Exactly one inline script and stylesheet per file; favicon is a data URI.
- Static resource references are self-contained; no external CSS imports or resource URLs.
- No detected network APIs, JavaScript imports, dynamic code evaluation, or persistent browser-storage dependencies.
- Static HTML IDs are unique; literal ID selectors resolve to declared elements, including elements generated by the scripts.
- Constellation is the fixed exported variant; the version-switching handler is absent.
