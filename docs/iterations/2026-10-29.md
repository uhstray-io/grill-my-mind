## Defects found and corrected during iteration

1. **Partial findings omitted:** a root awaiting an answer had analysis, but the brief said none existed. Briefs now include current partial findings during pauses and subsequent continuation. Regression tests distinguish a revised premise from earlier findings.
2. **Duplicated CLI context:** default brief JSON contained the same content again as Markdown. JSON now returns structured sections only; explicit Markdown output is separate, with exact stdout accounting.
3. **Long question swallowed its answer:** a combined excerpt could truncate before reaching the answer. Question and answer excerpts now have separate bounds; both appear in browser and Markdown representations.
4. **Active editor replaced by polling:** value/caret restoration could still discard native undo history and interrupt IME composition. Polling now preserves the actual active control and defers reconstruction. A save from another node/map does not force replacement of the current editor; navigating home during a save also avoids dereferencing a missing map. Independent review exercised the actual handler code in an isolated VM harness.
5. **Unsafe text in exported Markdown:** source HTML/image syntax could be interpreted by another renderer. Exported excerpts are escaped as literal text; browser preview also escapes source content.
