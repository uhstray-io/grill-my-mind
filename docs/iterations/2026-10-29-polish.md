## Browser verification

`scripts/browser-smoke.mjs` is an optional development check. It requires an existing Playwright installation and an explicitly selected Chromium-based browser executable; it adds no runtime dependency to the portable skill. For example, pass your installed Playwright `index.mjs` and Brave executable:

```powershell
node scripts/browser-smoke.mjs --playwright '<absolute path to playwright/index.mjs>' --browser-executable 'C:\Program Files\BraveSoftware\Brave-Browser\Application\brave.exe'
```

It creates a disposable workspace under `.test-output/browser-*`, starts and closes its own localhost server and headless browser, and writes screenshots plus a JSON report. Fixtures are explicitly illustrative and do not invoke a model or access the owner's saved maps. The report records the browser version and passed workflows; runtime credentials elsewhere in that workspace must not be committed.

Browser coverage includes light/dark themes, nearby navigation, actual native undo and selection preservation through polling, read-only history and returning to a draft, brief download, scoped connection prompt, answer continuation, dragging with connected edges, keyboard positioning, persistence after reload, 1024/768/390/320-pixel layouts, new-map starters, delayed saves, keyboard focus, completed-branch preservation, changed-premise children, and map-scoped connection status.

This is real Brave browser execution in headless mode. It closes the earlier automated visual/interaction gap caused by a locked desktop; it does not claim hands-on mobile-device testing, screen-reader acceptance, or IME composition coverage.
